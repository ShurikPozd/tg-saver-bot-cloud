# Save & Sort Bot

Личный Telegram-бот для **сохранения и умной сортировки контента**. Пересылаешь посты, картинки, альбомы и голосовые — бот сам разбирает их по категориям, папкам и тегам с помощью ИИ.

Работает 24/7 в облаке: **Telegram (Telethon) → LLM (Groq) + Vision (qwen3.6) + Speech-to-Text (Whisper)**.

---

## Возможности

| Возможность | Как работает |
|---|---|
| 🗂 Авто-категоризация | ИИ понимает *о чём* контент (а не только тип файла) и создаёт/переиспользует категории: `Игры`, `Арты`, `Новости аниме`, `Продажи`… |
| 🖼 Анализ фото | Vision-модель описывает картинку → мем, арт, скриншот игры — в свою категорию |
| 🎙 Распознавание голоса | Whisper транскрибирует голосовые/аудио → сохраняются и категоризируются |
| 🧩 Папки и подпапки | Автоматически раскладывает по темам (`Игры/PS5`, `Кино/Marvel`) и создаёт подпапки при накоплении похожих постов |
| 🏷 Теги | Гибкая система тегов с иконками для перекрёстного поиска |
| 🔁 Защита от дублей | Проверяет, что фото/видео/текст ещё не сохранялись |
| 🔒 Автозамок | Ручные правки не смазываются автоматическим пересортированием |
| 🔍 Поиск | По тексту, тегам и дате |
| 🗑 Корзина | Удаление с отменой и безвозвратным далением |
| 📊 Статистика и дайджест | Сколько и чего сохранено; еженедельный обзор |
| 💾 Экспорт / бэкап | Полный JSON-экспорт архива + автоматическая страховка в Telegram |
| 🚶 Гостевой режим | Друзьям — только просмотр библиотеки |

## Стек

- **Telegram**: Telethon (MTProxy / прямое подключение)
- **ИИ**: Groq API — `qwen/qwen3.6-27b` (текст + vision), `whisper-large-v3-turbo` (STT)
- **БД**: SQLite (нет файлов — бот хранит ссылки/метаданные, медиа остаются в Telegram)
- **Развёртывание**: Docker, GitHub, Render (Web Service) + UptimeRobot
- Python 3.11 · aiohttp · aiohttp-socks

## Быстрый старт (локально)

```bash
git clone https://github.com/ShurikPozd/tg-saver-bot-cloud
cd tg-saver-bot-cloud
cp .env.example .env
```

Заполни `.env`:

```ini
BOT_TOKEN=телеграм_токен_бота        # @BotFather
API_ID=12345                          # my.telegram.org
API_HASH=hex_ключ                     # my.telegram.org
GROQ_API_KEY=gsk_...                  # console.groq.com/keys
```

Запуск:

```bash
docker compose up -d --build
```

## Развёртывание на Render (бесплатно)

1. Запушь проект в приватный GitHub-репозиторий.
2. **Render → New → Web Service** → выбери репозиторий, Runtime **Docker**, регион поближе к Telegram.
3. Добавь переменные окружения из `.env` (кроме `MT_PROXY_*` и `GROQ_PROXY` — на зарубежном хосте они не нужны).
4. **Create Web Service**.
5. Создай монитор в [UptimeRobot](https://uptimerobot.com) на `https://<service>.onrender.com/healthz` (интервал 5 мин), чтобы бесплатный тариф не засыпал.

Диск free-тарифа эфемерный: бот на старте автоматически **восстанавливает базу** из последнего экспорта в Telegram, поэтому данные переживают перезапуски.

## Команды

```
/categories  — папки и категории архив
/search      — поиск по тексту и дате
/stats       — статистика
/settings    — настройки
/dups        — найти дубли
/archive     — перенос старых постов в Архив
/help        — справка
```

Пересылай посты боту в личку — или добавь его в группу с правами и сохраняй сообщения оттуда.
