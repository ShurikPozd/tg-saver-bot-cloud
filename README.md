# Save & Sort Bot

Личный Telegram-бот для **сохранения и умной сортировки контента**. Пересылаешь посты, картинки, альбомы и голосовые — бот сам разбирает их по категориям, папкам и тегам с помощью ИИ.

Работает 24/7: **Telegram (Telethon) → LLM (Groq) + Vision (qwen3.8) + Speech-to-Text (Whisper)**.

---

## Возможности

| Возможность | Как работает |
|---|---|
| 🗂 Авто-категоризация | ИИ понимает *о чём* контент (а не только тип файла) и создаёт/переиспользует категории: `Игры`, `Арты`, `Новости аниме`, `Продажи`… |
| 🖼 Анализ фото | Vision-модель описывает картинку → мем, арт, скриншот игры — в свою категорию |
| 🎙 Распознавание голоса | Whisper транскрибирует голосовые/аудио → сохраняются и категоризируются |
| 🧩 Папки и подпапки | Автоматически раскладывает по темам (`Игры/PS5`, `Кино/Marvel`) и создаёт подпапки при накоплении похожих постов |
| 🏷 Теги | Гибкая система тегов с иконками для перекрёстного поиска |
| 🔁 Защита от дублей | Проверяет, что фото/видео/текст ещё не сохранялись |
| 🔒 Автозамок | Ручные правки не смазываются автоматическим пересортированием |
| 🔍 Поиск | По тексту, тегам и дате |
| 🗑 Корзина | Удаление с отменой и безвозвратным далением |
| 📊 Статистика и дайджест | Сколько и чего сохранено; еженедельный обзор |
| 💾 Экспорт / бэкап | Полный экспорт архива (gzip) + автоматическая страховка в GitHub-синк и канал-хранилище |
| 👥 Мультиюзер | У каждого пользователя свой изолированный архив, категории и настройки |

## Стек

- **Telegram**: Telethon (MTProxy / прямое подключение)
- **ИИ**: Groq API — `qwen/qwen3.8-27b` (текст + vision), `whisper-large-v3-turbo` (STT)
- **БД**: SQLite (нет файлов — бот хранит ссылки/метаданные, медиа остаются в Telegram)
- **Развёртывание**: локально на ПК (Windows, автозапуск) или Docker / Render
- Python 3.12 · aiohttp · aiohttp-socks

## Быстрый старт (локально)

```bash
git clone https://github.com/ShurikPozd/tg-saver-bot-cloud
cd tg-saver-bot-cloud
cp .env.example .env
```

Заполни `.env`:

```ini
BOT_TOKEN=телеграм_токен_бота        # @BotFather
API_ID=12345                          # my.telegram.org
API_HASH=hex_ключ                     # my.telegram.org
GROQ_API_KEY=gsk_...                  # console.groq.com/keys
```

Запуск:

```bash
docker compose up -d --build
```

## Запуск 24/7 (локально, Windows)

Бот держит постоянное соединение с Telegram по MTProto (Telethon). Из РФ удобно ходить
через локальный MTProxy (`MT_PROXY_HOST=127.0.0.1`, `MT_PROXY_PORT=1080`).

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\pip install -r requirements.txt
Copy-Item .env.example .env    # заполнить BOT_TOKEN, API_ID, API_HASH, GROQ_API_KEY
.\.venv\Scripts\pythonw.exe bot.py   # без окна консоли, лог в logs/bot.log
```

Логи пишутся в `logs/bot.log` (ротация 10 МБ × 5). Автозапуск при входе в систему и
перезапуск при падении — через Планировщик задач Windows.

## Развёртывание на Render (опционально)

1. **Render → New → Web Service**, Runtime **Docker**, регион поближе к Telegram.
2. Переменные окружения из `.env` (на зарубежном хосте `MT_PROXY_*` и `GROQ_PROXY` не нужны).
3. Health check: `GET /healthz` на `PORT`.

Диск free-тарифа эфемерный: после перезапуска бот сам **восстанавливает базу** из последнего экспорта. Порядок источников: **GitHub-синк** (основной) → **канал-хранилище** (свежие снимки) → seed-файл.

Чтобы GitHub-синк работал, включи в переменных окружения:

```ini
GITHUB_TOKEN=ghp_...              # токен с правом write на backup-репозиторий
GITHUB_REPO=user/tg-saver-backups # репозиторий-хранилище бэкапов
GITHUB_BRANCH=main
GITHUB_PATH=backups               # папка внутри репозитория
```

Автоматические копии: **ежедневно (04:00 UTC)** и **каждые N сохранённых постов** (`backup_every_posts`, по умолчанию 5) — тихие, файл в чат не присылается. Экспорт по команде `/export` (или кнопке) присылает файл `tg_saver_export.json.gz` (содержимое gzip) и обновляет GitHub-копию.

## Мультиюзер

Каждый пользователь Telegram, написавший боту, получает **свой изолированный архив**: отдельный файл БД, свои категории, теги, папки и настройки. Никто не видит чужие сохранения — хоть в личке, хоть в общей группе (в группе каждый сохраняет в свой архив).

- При первом запуске бот **мигрирует** старую единую БД (`saved_items.db`) в личный архив владельца (`OWNER_ID` из `.env`) — данные никуда не пропадают.
- `OWNER_ID` также получает восстановление при пустой базе: **GitHub-синк → канал-хранилище → seed-файл**. Для остальных архив создаётся пустым автоматически.

## Команды

```
/categories  — папки и категории архива
/search      — поиск по тексту и дате
/stats       — статистика
/settings    — настройки
/dups        — найти дубли
/archive     — перенос старых постов в Архив
/export      — выгрузить архив (файл + GitHub-копия)
/help        — справка
```

Пересылай посты боту в личку — или добавь его в группу с правами и сохраняй сообщения оттуда.
